# Browser privacy integration

BPB Desktop does not build or bundle its own browser extension.

For browser language and time-zone alignment with the VPN exit IP, BPB recommends **GeoSpoof**, an independently developed, free browser extension.

- Official website and browser-specific installation links: https://geospoof.com/
- Upstream source code: https://github.com/GeoSpoof/geospoof
- Upstream license: Apache-2.0

Users install GeoSpoof directly from the official browser store and configure **Sync with VPN** and **Reported Language** themselves. BPB does not install, update, configure, or control this third-party extension. GeoSpoof's WebRTC feature is not required by BPB; BPB's own WebRTC protection remains separate.

GeoSpoof is third-party software, not a BPB product. Review its permissions and privacy policy before installing.
